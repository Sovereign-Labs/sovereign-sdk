# @sovereign-sdk/serializers

## 0.3.0

### Minor Changes

-   3208eb5: Internal transaction types have been renamed: `UnsignedTransaction` now refers to the user-constructed transaction data, and `TransactionSigningPayload{V0, V1}` is the version-dependent structure serialized for signing. Normal usage should be largely unaffected.
-   336d302: Support schemas that record tuple struct (e.g. newtype) names, from sov-universal-wallet 0.5.0.
    -   Schemas now carry a `type_name: string | null` on `Tuple` types (`null` for plain tuples and enum variant contents). The field is informational: display output, JSON-to-borsh parsing and EIP-712 encodings are unchanged (except for the changed chain hash).
    -   Schema JSONs generated by older versions of sov-universal-wallet (without the field) still parse.
