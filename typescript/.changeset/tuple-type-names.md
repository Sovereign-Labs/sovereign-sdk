Support schemas that record tuple struct (e.g. newtype) names, from sov-universal-wallet 0.5.0.
- Schemas now carry a `type_name: string | null` on `Tuple` types (`null` for plain tuples and enum variant contents). The field is informational: display output, JSON-to-borsh parsing and EIP-712 encodings are unchanged (except for the changed chain hash).
- Schema JSONs generated by older versions of sov-universal-wallet (without the field) still parse.
